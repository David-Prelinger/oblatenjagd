# Jump n' run 

I want to develop a jump and run game similar to super mario bros. It should have levels that go from left to right. It should be in pixel art. 

Architecturally, we run in a dev container, where I could see graphical program in vnc viewer. But ideally, we strucutre the software architecture so that it can run in wasm in the browser later on.

The theme of the game is the Salzkammergut. The language is german. It should involve a journey from Salzburg along the route of St. Gilgen, Brunnwinkel, St. Wolfgang Kloster auf dem falkenstein, St. Wolfgang, the Wolfgangsee lake, Strobl and until Bad Ischl and result in the cafe zauner. The coins of the game are zauner oblaten. It should be a fun and satirical of the salzkammergut and involve some tropes like people in lederhosen and dirndl, sailing on the wolfgansee lake, local history, traundl boats and the like.
